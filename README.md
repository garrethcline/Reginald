# Reginald

Reginald is an AI document assistant with the manners of a butler. Paste a document or upload a PDF, ask questions, and Reginald answers from that document. It is a single HTML file that runs in the browser; you bring your own API key (Anthropic or OpenAI), and the key stays in your browser.

Built in March 2026 as a companion to The Leigh Household Butler Book, my capstone project at The International Butler Academy.

## AI use

Two kinds. The app calls an AI model to answer questions. The app itself was also built with AI assistance: I set the behaviour, the persona and the design, used AI tools to write and revise the code, and tested the result.
